# Event-Driven Programming Lab

A hands-on Week 4 practical demonstrating event-driven programming concepts
using vanilla HTML, CSS, and JavaScript.

## What's Covered

- **Basic event handling** — responding to button clicks and reading input values
- **Event delegation** — handling clicks on dynamically created elements via a parent listener
- **Error handling** — validating input and displaying error messages
- **Observer pattern** — notifying multiple elements when state changes
- **Preventing content copying** — blocking text selection and copy events
